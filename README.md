# SnackCheck-automation-n8n-practice
Proyecto de practica de automatizacion de flujos con n8n

## Estructura

- `workflows/`: flujos exportados de n8n.
- `diagrams/`: diagramas de Excalidraw.
- `tests/FLOW_TESTS.md`: casos y notas de prueba del flujo en Markdown.
- `CHANGELOG.md`: historial de cambios del proyecto.
